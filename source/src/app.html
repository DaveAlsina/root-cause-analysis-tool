Versions

A version is a named snapshot stored inside this RCA file. Save one after each meaningful step, such as an interview or a literature pass. Restoring a version can be undone.

Categories

Build your own colour key. Give each category a meaning, and optionally a rule for what it means in the chain: an intermediate cause should have deeper causes, a root cause should end its chain. Boxes that break their rule are listed under Colour key checks. + lighter and + darker add shades, for example for degrees of doubt.

Replace with a draw.io diagram

In draw.io use Extras → Edit Diagram and copy everything. Raw, URL-encoded and compressed diagrams all work. This replaces the boxes and arrows in the current file; the version history stays, and Ctrl Z brings the old content back.

How it works

Arrows run from an effect to the cause that explains it, so each step to the right answers “why?”.

Add a boxDouble-click empty space, or select a box and press Tab to add a cause under it
Edit textDouble-click a box, or press Enter. With several languages, Enter moves on to the next language; Shift Tab goes back. Notes, sources, tags and status are in the side panel
TagsPick them in the side panel. Click a tag in the row above the diagram to highlight its boxes, or search #harvest

Saving. In Chrome and Edge, Ctrl S writes straight into the file you opened. Firefox, Zen and Brave download a fresh copy instead; replace your old file with it. Your work is also kept in this browser between sessions, so closing the tab does not lose it.

Outline = status. Dashed amber: hypothesis. Solid green: supported by evidence. Dotted red and faded: refuted. A red glow marks boxes caught in a loop (circular reasoning).

Roman numerals appear in Untangle when shared causes are split: the number says how many times that box appears.

Tags

Tags say where in the chain a cause happens. A box can carry several. Their order here is the order shown everywhere, so keep the product-flow tags in chain order. Each box shows its tags as emojis in its top-left corner; the tag row above the diagram highlights them.

Languages and title

Everything a reader sees (box texts, category and tag names, the title) is kept once per language, in one file. The main language is the one you write in first.

New root-cause analysis

Will you share this diagram in other languages too? Every box text will be asked for in each one.

Publish copy

Makes a read-only copy for other people. Readers can zoom, search, focus on branches, filter by tag and switch language, but cannot edit. Everything you include here is public.

GitHub Pages: put rca.json in the docs folder of the repository and push; the site shows it. Share link: the whole diagram travels inside the link, nothing is stored on a server.

Start an interview

The diagram locks: you can only grade boxes, note why, mark branches as discussed and add causes the interviewee proposes. Every click is saved in this browser. Edit mode is one click away and keeps the grades.

End interview

Saved as . It holds the diagram as it is now plus this interview's grades, notes and times. A copy also stays in this browser.

Finishing removes the grades from this working file, so the next interview starts clean. Boxes added during the interview stay, marked as proposed by it.

Grading scales

Each scale is a whole-number range, for example 1–3 or 0–5. The first scale gets the number keys, the second Shift + number, the third Alt + number. A scale can be asked only when another one is high enough, for example feasibility only when relevance is 3 or more.
